# Scrum PM Notes

A minimal static website for the Scrum Project Management study notes (MBA OM, Semester III). It has no build step and no dependencies: plain HTML, CSS and JavaScript.

## What's inside
```
index.html          the website (dashboard, sidebar, search palette, self-test, flashcards)
assets/style.css    styling
assets/app.js       loads and renders the notes
assets/notes.js     all notes bundled into one file (generated by build.py)
assets/marked.min.js  Markdown renderer (marked v12, MIT licence)
notes/*.md          the original Markdown notes (also readable on GitHub)
build.py            re-bundles notes/*.md into assets/notes.js
vercel.json         Vercel settings
```

## Preview on your computer
Double-click `index.html`. It works offline because the notes are bundled in `assets/notes.js`.

## Put it on GitHub (no command line needed)
1. Unzip the folder.
2. Go to https://github.com/new, name the repository (for example `scrum-pm-notes`), keep it **Public** or **Private**, and click **Create repository**.
3. On the new repository page click **uploading an existing file**.
4. Open the unzipped `scrum-pm-notes` folder, select **everything inside it** (`index.html`, `assets`, `notes`, `build.py`, `vercel.json`, `README.md`) and drag it onto the page. Don't drag the outer folder itself, or the site will end up one level too deep.
5. Click **Commit changes**.

Command-line alternative:
```bash
cd scrum-pm-notes
git init && git add . && git commit -m "Scrum PM notes site"
git branch -M main
git remote add origin https://github.com/<your-username>/scrum-pm-notes.git
git push -u origin main
```

## Host it on Vercel
1. Go to https://vercel.com/new and sign in with GitHub.
2. Click **Import** next to your `scrum-pm-notes` repository (grant Vercel access to it if asked).
3. Framework preset: **Other**. Leave the build command and output directory empty. The root directory is `./`.
4. Click **Deploy**. You get a link like `https://scrum-pm-notes.vercel.app`.

Every time you push a change to GitHub, Vercel redeploys automatically.

## Editing notes later
1. Edit a file in `notes/`.
2. Run `python3 build.py` to refresh `assets/notes.js`.
3. Commit and push (or upload both changed files on GitHub). Vercel updates the site.

If you edit only on GitHub's website and can't run Python, upload the updated `assets/notes.js` as well, because the site reads from that file.

## Using the site
- **Search anywhere:** press `/` or `Ctrl K` (`⌘K` on Mac) to jump to any chapter, section or definition, or to any sentence in the notes.
- **Self-test:** turn on the Self-test switch to hide every Q&A answer behind a "Reveal answer" button.
- **Flashcards:** every glossary definition as a flip card (Space to flip, arrow keys to move, Shuffle to mix).
- **Glossary:** about 150 definitions with A–Z filters and instant search.
- **Progress:** mark chapters as done; progress is saved in your browser.
- **Labels:** High-yield / Important pills mark exam priority; Slides / Textbook chips show where each point comes from.
- Light and dark themes, a reading-progress bar, an "On this page" panel, and print-friendly pages.
