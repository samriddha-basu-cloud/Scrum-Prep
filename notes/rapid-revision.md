## ⭐⭐ Formulas
- **Sprints needed** = remaining story points ÷ average velocity.
- **Little's Law:** cycle time = WIP ÷ throughput.
- **Flow efficiency (faculty):** cycle time ÷ lead time.
- **NPV** = Σ CF ÷ (1 + r)^t − investment; accept if > 0.
- **ROI** = net benefit ÷ cost × 100.
- **AgileEVM:** SPI = EV ÷ PV, CPI = EV ÷ AC, where EV = % points done × budget and PV = % sprints done × budget.

## ⭐⭐ How to write a 10-mark answer
1. One-line definition (use faculty wording where possible).
2. Diagram or table.
3. 6–8 explained points, each with an example.
4. Link to an Agile value/principle or Scrum value.
5. Two-line conclusion (when to use, benefit).

## Quick-fire checks (📘 answer keys)
Chart of work left → **Burndown** · Scope and done on separate lines → **Burnup** · Points per sprint → **Velocity** · Time without interruption → **Ideal** · Cancel a sprint → **Product Owner** · Sprint ends when timebox → **Expires** · Knowledge from experience → **Empiricism** · Kanban means → **Signal card** · Lean is a → **Mindset** · Continuous improvement → **Kaizen** · Writing tests first → **TDD** · Most effective communication → **Face-to-face** · Primary measure of progress → **Working software**.
